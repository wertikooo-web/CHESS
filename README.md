# ♛ Шахматы — браузерная игра

Полноценные шахматы в браузере: **HTML + CSS + JavaScript**, без сервера и установки.

**Играть онлайн:** [wertikooo-web.github.io/CHESS](https://wertikooo-web.github.io/CHESS/)

Репозиторий: [github.com/wertikooo-web/CHESS](https://github.com/wertikooo-web/CHESS)

---

## Как запустить локально

1. Скачайте или клонируйте репозиторий.
2. Откройте файл **`index.html`** в браузере (Chrome, Firefox, Edge и т.д.).

Сервер не нужен — достаточно двойного клика по файлу.

```text
CHESS/
├── index.html      ← главная страница
├── css/
│   └── style.css
├── js/
│   └── chess.js
└── README.md
```

## Возможности

### Игра
- Полные правила: ходы всех фигур, рокировка, взятие на проходе, превращение пешки
- Шах, мат, пат
- Подсветка шаха и последнего хода
- История ходов с нотацией; клик по ходу — просмотр позиции
- Отмена хода / отмена нескольких ходов
- Захваченные фигуры

### Режимы
- **Против ИИ** (уровни: Легко → Максимум)
- **Два игрока** за одним устройством
- Выбор цвета (белые / чёрные)

### ИИ
- Minimax + alpha-beta
- Piece-square tables, порядок ходов, quiescence search
- Кнопка **«Лучший ход»** — подсказка по оценке движка

### Интерфейс
- Темы доски: классика, дерево, синяя, зелёная, коричневая, серая
- SVG-фигуры (одинаковый вид на всех системах)
- Анимация ходов (можно отключить)
- Звуки (Web Audio, можно отключить)
- Таймер 10:00 на сторону
- Координаты a–h / 1–8
- Полноэкранный режим
- Сохранение / загрузка партии (localStorage)

### Обучение и анализ
- Режим **«Обучение»** — краткие подсказки после хода
- **Анализ партии** — неточности и ошибки по оценке движка

### Мобильные устройства
- Адаптивная вёрстка
- Touch-управление
- Доска подстраивается под ширину экрана

## Управление

| Действие | Как |
|----------|-----|
| Ход | Клик (или касание) по фигуре, затем по клетке |
| Подсветка возможных ходов | Галочка «Ходы фигур» |
| Лучший ход | Кнопка «Лучший ход» |
| Новая партия | «Новая игра» |
| Просмотр истории | Клик по ходу в списке → «К партии» |

## GitHub Pages

3. Branch: `main`, folder: `/ (root)`
4. Сайт: `https://<логин>.github.io/CHESS/`

В корне должен быть **`index.html`**.

## Технологии

- Чистый **JavaScript** (без фреймворков)
- **CSS** (адаптив, темы)
- **SVG** для фигур
- ИИ на **minimax** (без внешних движков)
